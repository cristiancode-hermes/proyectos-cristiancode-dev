# Proyectos CristianCode.dev

Landing page and project directory for [cristiancode.dev](https://cristiancode.dev).

## About

A showcase of 33+ full-stack projects deployed under `*.proyectos.cristiancode.dev`. Each project has its own subdomain with SSL, served via Caddy reverse proxy.

## Features

- **Project catalog** — organized by category (Core, Gestión, Finanzas, Productividad, Social)
- **Live search** — filter projects by name or URL
- **Quick links** — to WebUI, Dashboard, Status, and DevSnips
- **Mobile-first** — responsive design with `clamp()` sizing
- **Dark theme** — gradient background with gold accent
